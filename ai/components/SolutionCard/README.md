# SolutionCard

솔루션 페이지에서 세부 서비스 하나를 설명하는 카드입니다. 누를 수 없는 카드라 hover 반응이 없습니다.

## Anatomy

1. Icon (32px, stroke 1.4)
2. Number
3. Title (`primary-300`)
4. Description (Body sm)
5. Related link (관련 소식 보기, 선택)

## Size

안쪽 여백 22px 22px 18px. 테두리 없이 `card` 바탕만 씁니다.

## Usage

- 관련 기사가 있을 때만 '관련 소식 보기' 알약(`rel`)을 붙입니다.
- 아이콘은 Icons 문서의 기능 아이콘 16종에서 고릅니다.
- 네 장을 묶어 Carousel 안에 둡니다.

## How to use

**Do** — 설명은 두 줄 안쪽으로 씁니다.

**Don't** — hover 효과를 넣지 않습니다. 누를 수 있는 카드처럼 보이면 안 됩니다.
