# Badge

짧은 정보를 붙이는 작은 알약 라벨입니다. 뉴스 상세의 사용 기술 태그에 씁니다.

## Anatomy

1. Label
2. Container

## Variants

| Variant | 클래스 | 모양 |
| --- | --- | --- |
| Default | `badge` | `border` 테두리 + `card` 바탕 + `foreground` 글자 |
| Solid | `badge badge-solid` | `primary` 바탕 + `primary-foreground` 글자 |

## Size

높이 22px, 좌우 9px, 12px 500, `radius-full`.

## How to use

**Do** — 기술 이름처럼 짧은 명사만 넣습니다.

**Don't** — 분류를 나타낼 때는 쓰지 않습니다. 분류는 CategoryChip을 씁니다.
