# Writing

sowallab의 독자는 제조기업의 영업·기획 담당자입니다. 50대 독자도 한 번에 알아듣는 쉬운 말로 씁니다.

## Voice

| 원칙 | 설명 |
| --- | --- |
| 쉬운 말 | 업계 용어는 풀어 씁니다. "도면(STEP·DWG 등)"처럼 일상어를 앞에 둡니다. |
| 명사형 제목 | 제목은 명사형으로 끝맺습니다. |
| 존댓말 평서문 | 소개 문장은 "~합니다", "~드립니다"로 씁니다. |
| 한 문장에 한 가지 | 쉼표로 세 가지 넘게 잇지 않습니다. |
| 이모지 없음 | 강조는 `primary-300` 글자색으로 한 구절만 줍니다. |

## Naming

| 경우 | 표기 |
| --- | --- |
| 본문 첫 등장 | 소월랩(sowallab) |

## Title

| Do | Don't |
| --- | --- |
| 도면으로 만든 3D로 제품 구조와 작동 설명 | 도면 기반 3D로 혁신적인 제품 경험을 제공합니다! |
| 제품 찾기부터 상담 문의까지 한 번에 연결 | 원스톱 고객 여정 솔루션 |
| 촬영 없이 3D로 제품 영상과 사진 제작 | 차세대 비주얼 콘텐츠 |
| 설비 검토와 사내 반복 업무를 데이터로 개선 | AI 기반 DX 혁신 |

## Button

동사로 짧게 씁니다. 4~8자가 적당합니다.

- 무료 3D 시안 신청
- 솔루션 보기
- 회사 소개서 받기
- 자세히 보기
- 관련 소식 보기

"클릭하세요", "지금 바로" 같은 재촉하는 말은 쓰지 않습니다.

## Notice

다음에 일어날 일을 한두 문장으로 씁니다.

> 신청 후 24시간 이내에 회신 메일로 웹 3D 시안 링크를 보내 드립니다.

## Error

무엇을 하면 되는지 씁니다.

- 회사명을 입력해 주세요.
- 메일 주소를 확인해 주세요.
- 개인정보 수집·이용에 동의해 주세요.
