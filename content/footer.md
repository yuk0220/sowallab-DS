# Footer

모든 페이지 아래에 놓이는 푸터입니다. 연락처와 주요 행동, 사이트 링크를 한곳에 모읍니다.

## Anatomy

1. Contact card — 로고, 한 줄 소개, 메일 주소
2. CTA — 회사 소개서 받기, 무료 3D 시안 신청
3. Link columns — 메뉴, 솔루션, 담당 조직
4. Copyright

## Size

| 항목 | 값 |
| --- | --- |
| 연락처 카드 반경 | `radius-footcard` 20px |
| 연락처 카드 안쪽 여백 | clamp(24px, 3.2vw, 40px) |
| 로고 높이 | 24px |
| 메일 주소 | clamp(22px, 2.4vw, 32px) 600 |
| 열 제목 / 링크 | 12px 600 / 14px |

## Responsive

860px 이하에서는 연락처 카드가 1열이 되고 링크는 2열로 바뀝니다. 480px 이하에서는 카드 버튼이 한 줄씩 꽉 찹니다.

## Usage

- 연락처 카드 뒤에 심볼을 3.5% 불투명도로 크게 깝니다.
- 저작권 줄 오른쪽 88px는 플로팅 버튼 자리로 비워 둡니다.
- '회사 소개서 받기'는 BrochureModal을 엽니다.

## How to use

**Do** — 메일 주소는 mailto 링크로 겁니다.

**Don't** — 푸터에 새 행동을 더하지 않습니다. 행동은 두 개로 유지합니다.
