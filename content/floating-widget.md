# FloatingWidget

화면 오른쪽 아래에 떠 있는 버튼과 안내 카드입니다. 화면을 가리는 모달 대신 무료 3D 시안을 안내합니다.

## Anatomy

1. Floating button (56px 원, 심볼 26px)
2. Badge (처음 방문 시 `primary-400` 점)
3. Panel — 그래픽, 제목, 설명, CTA, '오늘 하루 열지 않기'
4. Close button

## Size

| 항목 | 값 |
| --- | --- |
| 버튼 | 56px (모바일 50px), `neutral-800` 바탕, `shadow-fab` |
| 카드 폭 | 300px, `shadow-panel` |
| 그래픽 비율 | 16:7 |
| 화면 가장자리 | 20px |

## Behavior

- 첫 방문 때 홈에서 2.6초 뒤 한 번 자동으로 열립니다.
- '오늘 하루 자동으로 열지 않기'를 누르면 그날은 열리지 않습니다.
- 열리면 심볼이 45° 돌며 사라지고 `X`가 나타납니다.
- 카드 그래픽은 사진과 글자 없이 점 바닥 패턴으로 그리고, 카드가 열려 있을 때만 움직입니다.

## How to use

**Do** — 카드 안 CTA는 빛줄기 버튼(`btn-beam`)을 씁니다.

**Don't** — 화면 전체를 덮는 모달로 바꾸지 않습니다.
