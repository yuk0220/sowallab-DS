# FlowList

일이 진행되는 순서를 번호와 함께 보여 주는 목록입니다. 문의하기 페이지 왼쪽의 '진행 과정'에 씁니다.

## Anatomy

1. Number (12px `muted-foreground`)
2. Step name (14.5px 600)
3. Description (13px `muted-foreground`)

## Size

줄마다 위아래 `border` 선, 3칸 그리드(34px · 104px · 나머지), 위아래 18px.

## Responsive

960px보다 넓으면 양식 옆에 고정(sticky, top 96px)합니다. 640px 이하에서는 양식 위로 올라오고 칸이 28px · 92px로 좁아집니다.

## Content

1. 현황 파악 — 제품과 업무 환경, 활용 목적 확인
2. 우선 과제 선정 — 먼저 해결할 과제와 범위 결정
3. 시안 검토 — 시안으로 방향을 미리 확인·조정
4. 제작·구축 — 콘텐츠와 기능 구현, 단계별 공유
5. 활용 및 개선 — 현장 사용에 맞춰 보완

## How to use

**Do** — 단계 이름은 명사형으로, 설명은 한 줄로 씁니다.
