# Grid

일관된 간격과 그리드로 화면에 조화로운 비율과 정렬을 만듭니다. 간격은 4px 단위로 쌓고, 좁은 화면에서는 clamp()로 부드럽게 줄입니다.

## Spacing

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `space-1` | 4px | 탭 트랙 안쪽, 메뉴 사이 |
| `space-2` | 8px | 아이콘과 글자, 필터 사이, 라벨과 입력칸 |
| `space-3` | 12px | 마키 줄 사이, 입력창 좌우 |
| `space-4` | 16px | 카드 그리드 gap, 입력 2칸 gap |
| `space-5` | 20px | 플로팅 버튼 가장자리, 모바일 좌우 최소 |
| `space-6` | 24px | 히어로 요소 사이, 큰 버튼 좌우 |
| `space-7` | 28px | 뉴스룸 카드 좌우 |
| `space-8` | 32px | 배너 칸 사이, 푸터 열 사이 |
| `space-10` | 40px | 탭 아래 영역 제목 위 |
| `space-12` | 48px | 필터 위 |

## Container

콘텐츠는 최대 1280px 컨테이너 안에 가운데 정렬합니다.

| 항목 | 값 |
| --- | --- |
| 최대 폭 | 1280px (좌우 여백 포함) |
| 좌우 여백 | 화면 폭의 10%, clamp(20px, 10vw, 160px) |
| 좌우 여백 (≤860px) | clamp(20px, 6vw, 48px) |
| 뉴스 상세 폭 | 880px 한 열 |
| 헤더 높이 | 64px, 고정 |

## Section rhythm

섹션 사이는 넓게, 섹션 안은 좁게 둡니다.

| 항목 | 값 |
| --- | --- |
| 섹션 위 여백 | clamp(72px, 9vw, 128px) |
| 영역 제목과 카드 사이 | 24px |
| 카드와 카드 사이 | 16px |
| 폼 항목 사이 | 22px |
| 라벨과 입력칸 사이 | 8px |

## Layout

| 영역 | 데스크톱 | 줄어드는 기준 |
| --- | --- | --- |
| 홈 솔루션 영역 카드 | 4열 | 1100px 2열 → 560px 1열 |
| 솔루션 세부 카드 | 4장 한 줄 | 1100px 2.6장 → 900px 가로 스크롤 |
| 뉴스룸 | 3열, 선으로 나눔 | 1000px 2열 → 640px 1열 |
| 문의하기 | 진행 과정 5 : 양식 7 | 960px 1열 |
| 푸터 | 연락처 카드 + 3열 | 860px 2열 |

## Breakpoints

| 너비 | 바뀌는 것 |
| --- | --- |
| ≤1100px | 솔루션 영역 카드 2열 |
| ≤1000px | 뉴스룸 2열 |
| ≤960px | 문의하기 1열 |
| ≤900px | 솔루션 카드 가로 스크롤 |
| ≤860px | 햄버거 메뉴, 푸터 2열 |
| ≤760px | 배너 1열 |
| ≤640px | 모바일: 탭·칩 축소, 필터 한 줄 스크롤 |
| ≤560px | 솔루션 영역 카드 1열, 입력 1열 |

## Page structure

| 페이지 | 구성 |
| --- | --- |
| 홈 | 히어로 → 3D 로봇 뷰어 → 비즈니스 솔루션 → 사용 도구 → 무료 3D 시안 배너 |
| 솔루션 | 페이지 머리 → 탭 4개 → 영역 제목 → 세부 카드 4장 |
| 뉴스룸 | 페이지 머리 → 분류 필터 → 뉴스 그리드 |
| 뉴스 상세 | 뒤로가기 → 제목 → 날짜·분류 → 이미지 → 본문 → 기술 태그 → 관련 소식 |
| 문의하기 | 페이지 머리 → 진행 과정 + 2단계 양식 |

## How to use

**Do** — 페이지 머리와 히어로는 가운데 정렬, 그 아래 콘텐츠는 왼쪽 정렬합니다.

**Do** — 원본에 있는 22px, 28px 같은 값은 4의 배수가 아니어도 그대로 씁니다.

**Don't** — 미디어 쿼리로 여백 값을 여러 번 바꾸지 않습니다. clamp() 하나로 씁니다.
