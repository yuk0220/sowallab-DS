# Motion

움직임은 사용자가 상태 변화를 알아차리도록 돕습니다. sowallab의 움직임은 은은하게 두고, transform과 opacity만 움직입니다.

## Duration

| 동작 | 시간 | 곡선 |
| --- | --- | --- |
| 버튼 색·테두리, 화살표 2px 밀림 | 150ms | 기본 |
| 탭 선택 배경 이동 | 380ms | cubic-bezier(.32,.72,0,1) |
| 탭 글자색 | 200ms | cubic-bezier(.23,1,.32,1) |
| 탭 패널 내용 페이드 | 500ms, 카드마다 40ms 지연 | cubic-bezier(.25,.1,.25,1) |
| 안내 문구 교체 | 450ms | cubic-bezier(.25,.1,.25,1) |
| 페이지 전환 | 350ms, 6px 이동 | ease |
| 카드 hover 테두리 | 250ms | cubic-bezier(.23,1,.32,1) |
| 카드 hover 점 격자 | 450ms | cubic-bezier(.23,1,.32,1) |
| 뉴스 썸네일 2% 확대 | 500ms | cubic-bezier(.23,1,.32,1) |
| 플로팅 카드 열림 | 280ms | cubic-bezier(.2,.8,.2,1) |
| 모달 페이드 | 200ms | ease |

## Loop

| 동작 | 주기 |
| --- | --- |
| CTA 빛줄기 링 | 4.5초에 한 바퀴 |
| 카드 hover 점 격자 흐름 | 3.2초 |
| 히어로 구 떠오름 (8px) | 6초 |
| 도구 마키 | 64초 / 역방향 58초 |
| 3D 로봇 자동 회전 | 3초 동안 조작이 없으면 시작 |

## Beam

무료 3D 시안 CTA의 테두리를 따라 청보라에서 시안으로 이어지는 빛줄기가 돕니다. 두께 2px, 글로우는 없습니다.

| 버튼 | 동작 |
| --- | --- |
| 밝은 CTA (`btn-beam`) | 늘 켜져 있습니다 |
| 어두운 CTA (`btn-beam-dark`) | hover 때만 켜집니다 |

## Press

세그먼트 탭은 누를 때 scale .97로 살짝 줄어듭니다.

## Reduced motion

`prefers-reduced-motion: reduce`에서는 모든 애니메이션과 전환을 끕니다.

- 빛줄기는 70deg 위치에서 멈춥니다.
- 영상은 멈춘 화면으로 보여 줍니다.
- 마키는 줄바꿈된 목록으로 바뀝니다.

화면 밖이거나 다른 페이지에 있을 때도 히어로 배경, 로봇 3D, 플로팅 카드 패턴을 멈춥니다. 터치 기기에서 캔버스 배경은 30fps로 그립니다.

## How to use

**Do** — 크기와 위치는 transform으로 움직입니다.

**Don't** — width, top 같은 레이아웃 속성으로 움직이지 않습니다.

**Don't** — 튀는 곡선이나 글로우를 쓰지 않습니다.
